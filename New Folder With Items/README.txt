RUTH ENEKWE — PORTFOLIO WEBSITE
================================

FILES:
  index.html   → Main HTML file (open this in a browser)
  style.css    → All styles (responsive, mobile-first)
  script.js    → All JavaScript (loader, nav, form, etc.)
  ruth-photo.jpg → Your profile photo

HOW TO USE:
  1. Open index.html in any web browser to preview locally
  2. To go live, upload all 4 files to your web host (keep them in same folder)
  3. Update the canonical URL in index.html <head> with your real domain

CONTACT FORM:

  Test it by submitting the form — you'll receive emails at ruthenekwe@gmail.com

CUSTOMISATION:
  - Colors → edit :root variables at top of style.css
  - Add projects → duplicate the <article class="project-card"> block in index.html
  - Update courses → edit the .course-chip spans in the Education section
  - Add new sections → follow the same section pattern used throughout
